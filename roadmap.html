Roadmap

This page tracks major goals across versions. Items can move as priorities change, but this is the current direction for Window Manager.

Timeline

Major version goals

Focus areas by release generation.

v1.x

Stability & Ecosystem

Polish core behavior, reduce edge-case glitches, and improve onboarding/documentation.

  • Fix edge cases in resize + drag reorder behavior
  • Improve standalone binary parity with addon mode
  • Expand docs with troubleshooting and recipes
  • Add migration notes for config changes
In Progress
v2.x

Workflow Power Features

Introduce advanced controls for power users and multi-monitor heavy setups.

  • Named workspaces and layout presets
  • Per-monitor profile switching
  • Expanded IPC commands and event hooks
  • Optional keybind-focused control layer
Planned
v3.x

Automation & Intelligence

Smarter placement and automation rules tuned for specific app workflows.

  • Rule-based initial placement by app/title/class
  • Session-aware restore of monitor/layout state
  • Profile-driven behavior packs for work/gaming/streaming
  • Telemetry-free local usage insights for tuning
Exploration
